# 📱 DigitalDelight

**DigitalDelight** è un progetto universitario realizzato per il corso di **Tecnologie e Software per il Web (TSW)** — A.A. 2023/2024.

Si tratta di un **e-commerce** scritto in **Java "plain"** utilizzando **JSP e Servlet**, con **MySQL** come database, progettato per vendere **smartphone e accessori**.

---

## 🧰 Tecnologie utilizzate

- 🌐 Java (Servlet + JSP)
- 🛢️ MySQL
- 🖥️ HTML/CSS (front-end base)
- 📦 JDBC
- 🛠️ Tomcat (server di deploy consigliato)

---

## 🛍️ Funzionalità principali

- Visualizzazione catalogo smartphone e accessori
- Aggiunta prodotti al carrello
- Registrazione e login utenti
- Checkout e gestione ordini
- Sezione admin per gestione prodotti e utenti
